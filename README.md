# Brew & Co. — Single-Origin Roastery & Cafe

An artisan, specialty coffee roastery web application featuring online ordering, item customization, home brewing guides, digital stamp card rewards, and dark/light mode themes.

## Features

- **Specialty Coffee & Pastry Ordering**: Real-time drink builder with custom milk bases, syrup infusions, espresso shot dosage, and temperature controls.
- **Digital Tasting Pass**: 6-stamp auto-saving loyalty reward system with celebratory confetti and free drink redemption.
- **Home Brew Guide**: Interactive cup size calculator (1 Cup, 2 Mugs, Travel Mug, Large Carafe) and step-by-step pour-over routine.
- **Instant Dark & Light Mode**: Synchronous theme switching with smooth transitions and persistent state.
- **Mobile-First UX**: Responsive bottom sheets, touch-momentum horizontal scrollbars, and accessible touch targets.

## Tech Stack

- **Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Effects**: Canvas Confetti

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
